# Personal Budget Planner – Java Day 60

## Description
A Java-based application that helps users track income and expenses and calculate their remaining budget.

## Features
- Add income and expense transactions
- View all transactions
- Calculate total income and expenses
- Display remaining balance
- Generate category-wise expense summaries
- Search transactions by category
- Save records permanently in a text file

## Technologies
- Java
- ArrayList
- HashMap
- File Handling
- Object-Oriented Programming

## Files
- `Main.java`
- `budget.txt`

## How to Run
```bash
javac Main.java
java Main
```

## Concepts Used
Classes, Objects, Constructors, ArrayList, HashMap, File Handling, Searching and Data Aggregation.
